# Taskboard
A fully-featured Kanban-style task board where users can create tasks, drag them across board sections, and manage work visually — inspired by tools like Asana and Linear. (NextPlay Assessment)

Here is the link to the deployed website: https://taskboard-beryl-xi.vercel.app/

# How to use
- click "Add task" below the category you want to write your task
- click anywhere on the screen to save it
- To change category, drag and drop the task to the category of your choosing
